# 📈 FX Trade Warriors

A trader-focused full-stack web application that centralizes risk management, journaling, account tracking, and performance analytics into a single platform.

## 🚀 Live Demo

🔗 https://fxtradewarriors.github.io/fxtradewarriors/

---

## 📖 Overview

Most traders rely on multiple disconnected tools:

* Trading journals
* Excel spreadsheets
* Risk calculators
* Notes applications
* Prop firm trackers

Managing all these separately creates friction and often leads to lost data.

FX Trade Warriors solves this problem by providing a unified workspace where traders can manage their entire workflow from one application.

The long-term vision is to use the collected journal data to build personal Machine Learning systems for trading analysis.

# ✨ Features

## 🏦 Trading Account Management

Create and manage multiple trading accounts.

Supports:

* Prop Firm Accounts
* Live Accounts

Track:

* Phase 1 progress (8% target)
* Phase 2 progress (5% target)
* Initial balance
* Current balance
* Daily drawdown
* Maximum drawdown
* Account statistics

---

## 📒 Trading Journal

Log every trade with detailed information.

Track:

* Market
* Direction
* Entry price
* Exit price
* Stop loss
* Take profit
* Lot size
* Entry logic
* Exit logic
* Mistakes
* Lessons learned
* Entry session
* Exit session
* Trade duration

Additional tracking:

* Broker commission
* Swap costs

---

## 📊 Performance Analytics

Analyze trading performance.

Metrics:

* Total trades
* Winning trades
* Losing trades
* Win rate
* Net PnL
* Average Risk-to-Reward ratio
* Best trade
* Worst trade
* Total commissions paid
* Total swap paid

Filter analytics by:

* Overall performance
* Specific accounts

---

## 📏 Lot Size Calculator

Risk-based position sizing.

Features:

* Position sizing calculations
* Distance metrics
* Trade summaries
* Saved calculations

---

## 📖 Rule Book System

Create trading discipline rules.

Predefined rules:

* Maximum daily risk cap
* Maximum risk per trade
* Maximum trades per day

Custom rules:

* Unlimited custom rules
* Manual rule tracking

---

## 📅 Rule Reports

Generate daily rule adherence reports.

Track:

* Rule compliance
* Daily discipline score
* Historical performance

---

## 📄 Export System

Export trading data.

Formats:

* PDF
* CSV

Filters:

* Account filter
* Date range filter

---

## 🔐 Authentication

Authentication is powered by Supabase Auth.

Supported methods:

* Email + Password
* Google Sign In
* Password Reset
* Session Persistence

---

## ☁️ Cloud Database

Data is stored in Supabase PostgreSQL.

No important data relies on browser storage.

Data persists across:

* Browser refreshes
* Device changes
* Cache clearing
