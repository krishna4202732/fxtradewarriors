# FX Trade Warriors

A modern trading dashboard built for disciplined traders.

FX Trade Warriors combines position sizing, risk management, prop-firm drawdown monitoring, and trading journal analytics into a single web application designed to improve consistency and decision-making.

## Features

### Lot Size Calculator

* EURUSD and XAUUSD support
* Risk-based position sizing
* Risk-to-reward calculations
* Potential profit and loss projections
* Distance and pip/point metrics

### Prop Firm Risk Monitor

* Daily drawdown tracking
* Maximum drawdown tracking
* Risk usage monitoring
* Custom and preset prop-firm rules

### Trading Journal

* Trade tracking and review
* Account management
* Win rate statistics
* Profit and loss analytics
* Trade notes and lessons learned
* Performance dashboard

### User Experience

* Modern responsive interface
* Dark and light theme support
* Interactive trading visualizations
* Fast and lightweight design
* Built with vanilla HTML, CSS, and JavaScript

## Technology Stack

* HTML5
* CSS3
* Vanilla JavaScript
* Local Storage

## Project Goal

The objective of this project is to provide traders with a practical tool for managing risk, documenting trades, and improving consistency through data-driven review and analysis.
